## 二、实测体检现状与共性瓶颈透析

经针对全部在线站点的自动化探测，我们发现了三项最关键的共性瓶颈，这也是本次升级的重中之重：

### 1. MA-DPP 欧盟数字产品护照与独立 `sitemap-dpp.xml` 覆盖不均
- **现状**：`cosinechips.com`、`fosslubricants.com`、`tianyalimestone.com`、`widewayfootwear.com`、`custombentofactory.com` 已率先完成 MA-DPP 预渲染并上线 `sitemap-dpp.xml`。
- **待优化站点**：`leohygiene.com`、`shdhygiene.com`、`widewaygroup.com`、`sossenergy.com`、`dingmaoshoes.com` 尚未部署 `sitemap-dpp.xml`。
- **整改机制**：启动对应垂直 Skill 中的 `build_dpp_static_pages.py` 或 `build_hygiene_site.py`，根据 ISO 15459 规范将每个品类生成独立 `/dpp-{sku}` 落地页与 XML 地图。

### 2. Google Search Console 6 大未收录原因的站群批量化修复
- **现状**：在 `cosinechips.com` 上，我们成功通过 `ego-browser` 将全部 6 大原因（40 重定向、34 Canonical 规范页、8 重复页、1 noindex 页、56 发现未收录、1 抓取未收录）一键点击点亮官方 `Validation: Started`。
- **待优化站点**：`leohygiene.com`、`tianmaoshoefactory.com`、`shdhygiene.com` 等已在 GSC 中有属性记录的站点，普遍存在因旧 `.html` 路径、带参 URL 造成的未收录队列堆积。
- **整改机制**：开发 `scripts/gsc_fleet_operator.js`，支持传入域名数组循环自动切换 GSC 资产，自动点击触发全站点 Validation。

### 3. `/llms.txt` (v2) 与生成式 AI 引用端点补全
- **现状**：大部分站点已具备 `/llms.txt`，但 `dingmaoshoes.com` 响应 404，部分站点未升级到 v2 标准（缺少 Wikidata QID 双向互锁）。
- **整改机制**：运行 `seo_geo_matrix.py` 批量生成 `/llms.txt`、`/llms-full.txt` 与 `/ai/*.json`。

## 三、沉淀到总控与子 Skill 的四大新增技术资产

为系统化承接这 28 个站点的全量优化，本次在 `b2b-export-site-super-orchestrator` 中沉淀了以下核心资产：
1. **多域名站群巡检器 (`scripts/fleet_site_auditor.py`)**：单命令并发测试 28 个站点的 DNS 解析、HTTP 状态、Sitemap、DPP 地图、`llms.txt` 与 `robots.txt`；
2. **多域名 GSC 自动化舰队操作器 (`scripts/gsc_fleet_operator.js`)**：批量循环切换 GSC 属性，自动化触发所有站点的 6 大原因 Validation；
3. **新增垂直 Skill 1**：[`b2b-hygiene-export-site-builder`](https://github.com/cnproduct/b2b-hygiene-export-site-builder)（涵盖 `leohygiene.com`、`shdhygiene.com`、`chinabaronhygiene.com`）；
4. **新增垂直 Skill 2**：[`b2b-energy-storage-site-builder`](https://github.com/cnproduct/b2b-energy-storage-site-builder)（涵盖 `sossenergy.com`，对齐欧盟新电池法案 EU Battery Passport 2023/1542）。
